Built around the timeline

The essentials, in one focused workspace.

Rex One Track pairs a visual HTML-canvas preview with native media export. The Windows wrapper keeps the processing close to your files.

01

One bin for your media

Import video, audio, and still images into the media bin, then add items to the main or audio lane.

02

A timeline you can shape

Preview and seek through your sequence, adjust clips, split at the playhead, detach video audio, zoom to fit, and save or reload jobs.

03

Subtitle spotting tools

Load SRT, VTT, or text lines; spot cue in/out points, skip or revisit a line, and adjust subtitle size and alignment.

04

Preview before export

See a canvas-based preview, move subtitle placement, and refine the timing against your timeline.

05

Formats for the finish

Render video as MP4 or WebM, audio as MP3, and export spotted subtitle cues as SRT.

06

A local desktop workflow

The wrapper transfers selected media to a temporary folder on this PC, runs FFmpeg locally, then cleans up temporary files when it closes.

Getting started on Windows

Unzip the bundle. Open the app. Make a cut.

Rex One Track is a Windows wrapper package, not a browser-hosted editing service. Keep the distributed files together so the app can find its page and FFmpeg tools.

Download the release bundle

Get the ZIP attached to the project's GitHub Release. A Pages site cannot serve a repository-relative bin folder as the downloadable app package.

Extract the full folder

Keep html-wrapper.exe, index.html, and the ffmpeg folder together. The folder must include both ffmpeg.exe and ffprobe.exe.

Launch the wrapper

Run html-wrapper.exe. It opens the bundled app in an installed Chrome or Edge app window, or a supported portable browser beside the executable.

Build and export locally

Import media, arrange the timeline, and export. Processing uses the native wrapper and FFmpeg on this computer; this site does not process your media.

Ready to make your timeline?

Download the complete Windows bundle from a GitHub Release, then extract it before launching. The release URL is intentionally not guessed or hard-coded to an unverified repository.

For maintainers: publish the complete app bundle as a Release asset (for example, a ZIP containing the contents of bin). Configure the single RELEASE_DOWNLOAD_URL constant in this page to its direct asset URL.

Media is processed locally by the desktop wrapper and FFmpeg; selected media is copied to a temporary folder on this PC and removed when the wrapper closes. Rex One Track is not a browser-hosted media processing service. The wrapper also makes a startup check against its configured version endpoint. This static site and its interactive preview make no network calls and use no tracking or third-party runtime assets.
