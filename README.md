# Rex One Track — Make every moment line up

> Local-first Windows timeline editor for video, audio and subtitle spotting.

## Quick Guide

[Rex One Track - Quick Guide](rex-quick-guide-final.png)

### How it works
- **IMPORT** — Import audio, video and images.
- **EDIT** — Edit them on Track.
- **DETACH & SPLIT** — You can also detach audio / video and split media.
- **LOAD SUBTITLES** — Load text / SRT subtitle file; play the compiled video; and add lyrics / subtitles by spotting ( easy method of adding subtitles )
- **EXPORT** — Then Export your compiled work and test the results.
- **SPOT WITH KEYS** — Spott subtitle with arrow keys whilst the media is playing.
  - ▲ Skip
  - ▼ Enter
  - ▶ End displayed subtitle
  - ◀ Delete last

> Media is processed locally by FFmpeg wrapper. Temp files removed when wrapper closes. No upload, no tracking.
